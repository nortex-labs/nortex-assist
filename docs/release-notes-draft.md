## Nortex Assist 1.3.0 · 2026-11-01

Скриншот области стал удобнее и работает без лишнего клика, а в простое программа почти не занимает память.

### Новое
- Свой выбор области для Alt+W: экран замирает, вы обводите нужное мышью и видите размер. Клик без выделения снимает весь экран, Esc отменяет.
- Способ скриншота выбирается в настройках («Поведение»): «Выделить область», «Весь экран» или «Ножницы Windows».
- Настройка «Отображать приложение в трее» (включена по умолчанию). Без значка окно открывается по Alt+E.
- Свой акцентный цвет: радужный кружок в «Внешнем виде» открывает палитру, можно вписать HEX или RGB.
- В пустом окне слева сверху видны логотип и название, они окрашены в акцентный цвет.

### Улучшено
- Когда окно спрятано, программа отдаёт память Windows и почти не занимает оперативной памяти.
- Плавные анимации окна, панелей, кнопок и подсказок. Пока идёт запрос, видна бегущая полоска и «Думаю».
- Кнопка отправки стала серой и загорается акцентным цветом при наведении.
- Разделы настроек поменялись местами: «Внешний вид» теперь 02, «Стиль ответов» 03.
- Ответ начинается сразу под вопросом, без пустого промежутка.
- Кнопки ответа (повтор, копирование, листание) видны, только когда есть ответ.
- В истории время показано понятнее: «сегодня, 14:05».

### Исправлено
- Окно со скриншотом появлялось только после лишнего клика по экрану.
- Перед выделением области на мгновение было видно незатемнённое промежуточное окно.
- При низкой прозрачности строка ввода была видна лучше остального окна. Теперь прозрачность одинаковая для всего окна.
- Прозрачность иногда сама сбрасывалась на прежнее значение. Теперь ползунок сохраняется сразу.
- Если горячая клавиша была занята другой программой, настройки не закрывались. Теперь программа предупреждает, сохраняет остальное и закрывает настройки.
- В светлой теме акцентные надписи плохо читались.

### Важно
- Ничего делать не нужно, обновление ставится автоматически.
- Хранилище переехало на github.com/nortex-labs/nortex-assist. Обновления продолжают приходить, старые ссылки перенаправляются.
